CASE STUDY 01 / MOBILE SOCIAL PRODUCT

Chongqing
Hangout.

重庆约玩：基于共同兴趣的本地活动社交产品

从发现活动、建立连接到报名参与，设计一条可以自然发生的线下社交路径。

ROLE / 角色
UX Strategy · Product UI
FOCUS / 核心
Discover · Connect · Join
OUTPUT / 产出
App Flow · Visual System

THE PROJECT / 项目一句话

让用户先找到想做的事，再遇见愿意一起做这件事的人。

以地点、兴趣和活动为入口，降低陌生人线下社交的决策成本与信任门槛。

CASE CONTENTS
案例内容

01 Brief 需求定义 02 Architecture 信息架构 03 System 设计系统 04 Screens 页面设计

01

REQUIREMENT BRIEF / 需求定义

Start with a clear social question.

不是设计“更多活动”，而是设计一条让用户愿意走进去的社交路径。

DESIGN GOAL / 设计目标从「今天去哪」到「一起去」

将活动发现、同伴连接与报名参与串成连续体验，减少用户在每个节点的犹豫。

01Discovery / 发现快速看到附近值得参与的活动

02Connection / 连接通过共同兴趣建立参与意愿

03Participation / 参与带着足够信息完成报名决策

02

INFORMATION ARCHITECTURE / 信息架构

Make the loop visible.

围绕“发现—连接—参与”组织页面关系，让每个下一步都能被理解。

03

DESIGN SYSTEM / 设计系统

One visual language.

以温和的绿色和高可读的信息层级，建立轻松、可靠的本地社交氛围。

04

KEY SCREENS / 页面设计

Designed for
the whole loop.

把关键动作放在用户最需要它的时刻：找活动、看消息、表达自己、创建与参与。

02 / WELCOME FLOW

Welcome & onboarding 欢迎引导 · 08

首次进入产品的欢迎、账户、偏好与权限路径。

01 / CORE JOURNEY

Discover to join 核心路径 · 05

用户进入产品后，从看见活动到建立连接、完成参与的关键页面。

点击任意页面可进入高清预览，使用键盘左右方向键或页面按钮切换。
